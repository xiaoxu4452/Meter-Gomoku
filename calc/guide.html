Meter Web 使用说明Meter Web — user guide

METER GOMOKU · WEB · RAPFI NNUE WASM

Meter Web 是把桌面版 Meter Gomoku 的「计算部分」搬到浏览器里的版本：同一颗 Rapfi 引擎、同一套 NNUE 权重，用 WebAssembly 在你的设备上本地推理。没有服务器、没有排队，摆好局面就能算。

Meter Web brings the analysis half of the desktop Meter Gomoku into the browser: the same Rapfi engine and NNUE weights compiled to WebAssembly, running locally on your device. No server, no queue — compose a position and analyse it.

二、棋盘操作2. Playing on the board

  • 点交叉点落子，黑先；点刚下的那颗棋子可以撤回，上一步 / 下一步 也能前后翻。
  • 桌面端可以右键撤回，手机长按棋盘同样撤回。
  • 开启「显示手数」后，每颗棋子上写着第几手；最后一手的数字是红色。
  • 候选点上会画一个圆：上半是胜率，下半是评分；颜色越靠前（青 → 绿 → 黄）排名越低。
  • Tap an intersection to play; Black moves first. Tap the stone you just played to take it back, or use Undo / Redo.
  • Right-click on desktop, long-press on a phone — both undo.
  • With “Move numbers” on, every stone shows its move number; the last one is red.
  • Candidate circles show the win rate on the upper half and the score on the lower half; the colour order (cyan → green → yellow) follows the ranking.

四、仪表盘与胜率4. Dashboard and win rate

  • 深度 / 速度 / 节点 / 用时：搜索结束后保留最后一次的数值，不会被清空；只有重开或载入新局才归零。
  • 胜率：上面一行是「黑 xx% / 白 xx%」，下面是荧光细条——开局左右各一半，谁的优势大谁那一侧变长。
  • 胜率行中间的分数：黑子 / 白子两个格子一直都在，分别套紫白框与蓝白框；还没算出来时显示「-」，算完就一直保留，只有重开或换局面才清空。
  • 棋盘右上角：只用和坐标字符同样的字体写着最新一手的坐标（例如 K12），没有边框也没有底色。
  • 分析路线：`d24 +37 H8 G7 ...` 依次是深度、评分、主变坐标。把鼠标移到某个坐标上（手机点一下），棋盘会把这个点之后的走法半透明地摆出来，虚线圈标出当前悬停的那一手，再点一次收起。
  • Depth / speed / nodes / time keep their last values after a search stops; only a new game or a loaded position clears them.
  • Win rate: the row above reads “Black xx% / White xx%”, the neon bar below splits in that ratio — even at the start, longer on the side that is winning.
  • Score chips in the middle of that row: black and white are always both present, framed purple-white and blue-white; an unknown score reads “-” and the last value stays until the position changes.
  • Board top-right: the newest move's coordinate (e.g. K12), set in the same face and colour as the axis labels — no box, no border.
  • Main line: `d24 +37 H8 G7 ...` is depth, score, then the moves. Hover a move (tap on a phone) and the board previews the continuation in translucent stones, with a dashed ring on the hovered move; tap again to hide.

六、加载与离线6. Loading and offline use

  • 引擎与权重约 41 MB，第一次打开会有一个毛玻璃弹窗显示真实的下载进度；下载完会写进本机缓存，之后打开几乎是瞬时的。
  • 站点本身走 GitHub Pages，国内可能不通，此时会自动改走公共加速镜像，界面上的百分比照常走。
  • 缓存是分层的：更新界面不会重新下载 41 MB 的引擎；需要强制重来时，在设置里清除站点数据即可。
  • 断网也能用——本地推理，不依赖服务器。
  • The engine and weights are about 41 MB. The first visit shows a frosted panel with the real download progress; afterwards it is cached locally and opens almost instantly.
  • The site is served from GitHub Pages, which is slow or blocked in some networks, so the engine files fall back to public mirrors automatically — the percentage keeps moving either way.
  • Caching is layered: shipping a new UI does not re-download the 41 MB engine. Clear the site data if you ever need a clean slate.
  • It works offline: inference is local, no server involved.

七、和桌面版、官方计算器怎么分工7. How it relates to the desktop app and the official calculator

  • Meter Web（这里）：手机随时打开，界面与桌面版同源，只有计算相关功能。
  • 桌面版 Meter Gomoku：能拿到更多线程与更大的置换表，同样时间算得更深，另有对弈、复盘、识图、连线。
  • Rapfi 官方计算器（gomocalc）：Rapfi 作者维护，界面更朴素，胜在权威与稳定。
  • Meter Web (here): open it on a phone any time; the interface mirrors the desktop build and keeps only the calculation parts.
  • Desktop Meter Gomoku: more threads and a larger hash, so it searches deeper in the same time, plus play, review, vision and Link.
  • Rapfi official calculator (gomocalc): maintained by the Rapfi author, plainer but authoritative.

八、常见问题8. FAQ

为什么线程数只有 1？Why is the thread count stuck at 1?

多线程需要页面处于「跨源隔离」状态。本站在正常访问时由 Service Worker 注入所需响应头；如果被浏览器禁用（隐私模式、拦截扩展），引擎会自动降级为单线程，功能不受影响，只是慢一些。

Multi-threading needs the page to be cross-origin isolated. The service worker injects the required headers on normal visits; if that is blocked (private mode, aggressive extensions) the engine falls back to a single thread — everything still works, just slower.

设了 4 个点，为什么只看到 2 个圆？I asked for 4 points but only see 2 circles

相邻的候选点图画在一起会互相遮挡，所以只保留评分更高的那个。想要更多候选，可以调大「分析点数」，或换一个更开阔的局面。

Neighbouring candidates would overlap, so the stronger one is kept. Ask for more points, or look at a more open position.

局面代码怎么用？How does the position code work?

与 gomocalc 同格式：每手两个字符，列字母 + 行号，例如 h8h9g7f7i8。粘贴进「局面代码」框会立刻载入，点右边的按钮可以复制当前局面。

Same format as gomocalc: two characters per move, column letter plus row number, e.g. h8h9g7f7i8. Paste it into the position box to load immediately; the button beside it copies the current position.

手机上点局面代码框，界面会不会被键盘挤变形？Does the keyboard squash the layout on a phone?

不会。页面会记住键盘收起时的高度，键盘弹出时只把输入框滚到键盘上方，棋盘和按钮保持原尺寸；收起键盘后自动恢复。

No. The page remembers the height it had before the keyboard opened, so the board and the keys keep their size; it only scrolls the box above the keyboard and restores itself when you are done.

计算全部发生在你的设备上，局面不会上传到任何服务器。
Everything is computed on your device; positions are never uploaded.
